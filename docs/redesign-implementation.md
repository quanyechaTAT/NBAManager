## 2. 保护边界

- 保留原有哈希路由、实体 ID、业务能力、权限及参数；新增列表参数兼容。
- 登录 AI 使用 MainLayout；匿名分享只读，不请求私人会话、通知、比分和全站统计。
- 新闻、帖子、评论及历史 AI 回答原文未进行文案替换。
- 季后赛只优化标题、来源、刷新与管理入口。图本体模板、脚本、局部样式与五个内部组件均以重构前 HEAD 建立 SHA-256 基线。
- `playoff-legacy.css` 固定原主题变量与字体继承。源码保护通过不等于像素验收；四组图本体截图仍待检查。
- 球队、比赛原始 getter 保留，发布状态在 DTO、榜单和 RAG 层处理，避免改变季后赛内部数据组装和晋级逻辑。

## 3. 页面与工程清单

| 页面 / 路由 | 当前实现 |
|---|---|
| 平台总览 `/dashboard` | 日期、赛季、获取时间；比赛优先；排名、得分榜、热门讨论与紧凑工具 |
| 赛事与资讯 `/news` | 默认赛程；日期、状态、球队、赛事类型；资讯筛选分页恢复；newsId 阅读、来源、收藏和分享；0 与占位区分 |
| 比赛详情 `/match-detail` | 比分首屏及四标签；节末累计比分；投篮、复盘和聊天室按需加载 |
| 季后赛 `/playoff` | 外围标题、赛季、来源、普通刷新与管理员入口；图本体保持原样 |
| 球队排名 `/teams` | 统一筛选；来源战绩与本地样本分开；DIFF 与样本数；未知排名不授予资格；防乱序 |
| 球队详情 `/teams/detail` | 身份、阵容、比赛、交锋；赛季 / 类型同步；完整已收录比赛范围；0 分保留 |
| 球员数据 `/players` | 桌面表格 / 手机卡片及记忆；筛选排序；百分比排序修正；全部筛选导出；管理员行操作 |
| 球员详情 `/players/detail` | 六项原始统计与同赛季有效平均值；单指标生涯趋势和数值表；真实投篮筛选；比赛记录 |
| 球员对比 `/players/compare` | 选择、交换、身份、对照表、差值与单指标图；保留业务 ID / id1 / id2；使用率等不强行标优劣 |
| 选秀档案 `/drafts` | 年份、轮次、球队；实际收录人数；桌面表 / 手机卡；同步、编辑和球员入口 |
| 历史赛季 `/history` | 五项完整榜单接口；至少 10 场；逐指标有效样本；战绩；历史与当前资料区别；刷新保留当前范围缓存 |
| AI `/smart-search` | 会话侧栏、900px 阅读区、四类能力、比赛实际日期、流式回答、真实来源与实体入口 |
| 社区 `/community` | 内容列表、分类排序话题发布；当前页统计；规则侧栏与手机布局 |
| 讨论 `/community/post` | 阅读宽度、作者时间、楼层回复；互动入口；提交防重复与失败重试；作者 / 管理员权限 |
| 个人中心 `/profile` | 默认关注；收藏、历史、账户；头像、用户名、密码；标签参数恢复 |
| 登录 `/login` | 主站品牌双主题、手机滚动、自动填充、错误反馈、防重复和安全返回 |
| 注册 `/register` | 主题一致；用户名字符长度及密码规则匹配后端；真实后续路径 |
| 管理 `/admin/sync` | 健康、模块、真实任务、分页历史、步骤来源数量、取消终态；检索持久时间线与独立滚动日志 |

共用实现：语义主题与基础样式；导航和页面名称集中配置；列表筛选分页及内部滚动恢复；搜索 300ms 防抖 / 键盘 / 中文输入法 / 请求乱序；手机通知抽屉；401 / 403 分流；共享比分去重、轮询与 WebSocket 生命周期；来源组件区分上游和获取时间；Element Plus 按需引入，Excel / Markdown / 重型业务组件异步加载。

数据实现：DataMeta 的质量与字段状态统一发布规则；缺失返回 null，真实 0 保留；移除 USG%=20、TS%=FG%、默认场次及生物信息；E_OFF_RATING 不映射 PER；ID 保留。球队连续胜负不截断样本，DIFF 不冒充每百回合效率。历史指标在 LIMIT 前核验并独立计算均值。真实投篮有效集合替换，不造日期 / 坐标，失败保留来源缓存。Flyway 保存旧值快照，不按 20 / 110 / 0 判断占位。元数据按模块聚合，关联批量读取；Redis / RAG 使用数据契约 v2。

旧 global / components / motion / polish 四份全局样式留在库中但不再加载；剩余局部样式仍需结合运行页面继续收敛。

实际生产文件使用 gzip level 9，1 KiB = 1024 字节：球员列表自身脚本 **6.71 KiB**（目标 ≤30 KiB，初始约 101KB）；主框架共享 CSS **21.76 KiB**（目标 ≤50 KiB，初始约 63KB）。主框架初始 JS 约 177.65 KiB，球员页静态依赖 JS 约 219.97 KiB / CSS 约 32.51 KiB；自身脚本不是整页首次下载量。Excel、Markdown、图表不在主框架初始静态图中，Excel 不在球员页静态图中。此检查不测网络速度或 Core Web Vitals。

在 `frontend` 复现：

```powershell
npm run typecheck
npm run test
npm run build
npm run audit:bundle
```

在 `backend` 复现：

```powershell
.\mvnw.cmd test -q
.\scripts\venv312\Scripts\python.exe -m pytest scripts/tests -q
```

只读审计：`python backend/scripts/audit_data_provenance.py --help`；实际运行需显式配置目标库和只读账号。本轮未连接实际项目库执行该审计。
