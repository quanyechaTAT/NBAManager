## 附加场景

- 360 / 768 / 1024 / 1920px：导航、表格、AI、比赛、阅读层、管理；不出现意外整页横向滚动。
- 状态：首次加载、同范围刷新、无记录、筛选无结果、部分数据、来源不可用、请求失败、权限不足、禁用。
- 匿名分享：有效 / 空 / 无效 / 过期；只读；网络面板无私人历史、通知、比分及全站统计；登录后返回原分享目标。
- AI：中文候选确认不发送；Enter / Ctrl+Enter；取消保留生成部分；失败重试；导出保存分享删除；软键盘安全区。
- 功能：登录返回、普通 / 管理员、关注收藏评论回复头像账户、筛选排序全部导出、浏览器返回恢复。
- 无障碍：键盘主要操作、可见焦点、弹层进入 / Escape / 返回焦点、表单标签、200% 缩放、减少动态效果、阅读器表头状态摘要。
- 对比度：正文 4.5:1，大字和有意义控件 / 图形 3:1，测实际背景叠层。
- 性能：导出前无 Excel 请求，非图表页面无图表库，切换不重复轮询 / WebSocket，失败保留仍可用数据。
