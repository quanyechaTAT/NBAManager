浅色辅助文字调整为 #5E6D83，使其在次级容器也满足正文对比度。主按钮深色青底深字、浅色深青底白字；保存主题优先系统，并在挂载前应用。

正文目标 4.5:1；大字、控件及有意义图形边界 3:1。弱分隔线不代替输入等控件边界，后者使用 `--border-control`。实际页面需测叠层结果。状态配文字 / 图标；球队色用于身份和有说明的系列；季后赛本体使用独立旧样式边界。

## 排版与布局

- 本地系统字体栈，中文苹方 / 微软雅黑，数字 tabular-nums，无远程字体请求。
- 标题桌面 28px、手机 24px；区块 18–20px；正文 14–16px；阅读正文 16px；辅助 12–13px。
- 4px 基础间距；主要 8 / 12 / 16 / 24 / 32px；卡片 12px，按钮输入 8px。
- 常规最大 1440px、阅读 960px / 正文约 68 字符、AI 900px、新闻正文约 720px；左右桌面 24px / 手机 16px。
- 手机 ≤768px、平板 769–1199px、桌面 ≥1200px；交互 150–200ms，减少动态效果时关闭非必要动效；手机主要操作目标 44px。

## 信息架构与状态

顶部“总览、赛事、数据、AI 分析、社区”。赛事含赛程资讯季后赛，数据含球队球员对比选秀历史。账号“个人中心、账户设置、数据管理、退出登录”，管理仅管理员。

手机底部“总览、赛事、数据、社区、我的”，数据打开分组抽屉，AI 顶部快捷入口。详情带 returnTo，列表保存筛选分页和内部滚动。

首次骨架；同范围刷新保留旧内容；不同范围不混缓存。空状态区分无记录、筛选无结果、来源不可用、请求失败和权限不足。提交防重复，取消同步等真实终态。401 清会话 / 登录，403 保留登录。弹层进入 / Escape / 返回焦点，AI 手机抽屉限制焦点并将背景 inert。

搜索 300ms 防抖、方向键 / Enter / Escape / 中文输入法；新请求不被旧结果覆盖。浏览器通知授权由用户主动触发。

## 统计与来源

| 内容 | 表达 |
|---|---|
| 数量场次比分 | 整数；真实 0；未开始比分 — |
| 场均 | 通常一位小数 |
| FG% / 3P% / FT% / TS% | 接口 0–1，显示乘 100 与 % |
| USG% | 接口 0–100，不再乘 100 |
| pointDifferential / 兼容 netRating | 场均净胜分 DIFF，非每百回合效率 |
| BPM / PER / EFF / ORTG | 各自指标，只在字段核验后显示，不互相代替 |
| 节比分 | 节末累计比分 |
| 缺失 / 未核验 | —，不参与均值排名，排序末尾 |

DataMeta 区分未知来源、人工录入、未知上游时间与实际获取时间。来源仅使用已有 HTTP(S) 地址，不拼造证明链接。样本和范围靠近图表表格。

图表统一主题文字坐标轴背景；不同单位拆图；趋势不连空值；用名称标记补充颜色，提供原始值。同赛季平均值只在球员统计赛季明确时加载，各指标分别排除缺失 / 未核验。

## 文案

统一：平台总览、球队排名、球员数据、球员对比、选秀档案、历史赛季、篮球社区、个人中心、数据管理、比赛复盘、球员统计概览。

动作写明对象：查看比赛、发布讨论、导出全部筛选结果、刷新记录、同步指定模块。进度来自真实事件；AI 不按定时器猜阶段。取消回答保留部分并标“未完成”，不保存为完整服务端会话。新闻、用户内容和历史回答原文不改。
